# 达博理 — 产品路线图

## 已完成

### 基础架构
- [x] Next.js 16 + TypeScript + Tailwind CSS 4 项目搭建
- [x] Supabase Auth 集成（邮箱/密码、Magic Link）
- [x] 多学科数据架构（学科注册表 + 模块化数据源）
- [x] localStorage 学习数据持久化（进度/笔记/错题/成绩）
- [x] Vercel 部署 + GitHub CI

### 网络工程课程
- [x] 15 个模块、63 个课题的完整内容
- [x] 每课题含知识讲解 + 术语卡片 + 练习题（250+ 道）
- [x] 交互式图表组件（16 个：OSI、TCP/IP、VLAN、STP 等）

### 软考备考
- [x] 网络工程师（中级）— 6 个模块、55 个课题（复用网络工程数据）
- [x] 按考纲重新组织为计算机网络基础、网络互连、安全、管理、规划、新技术

### AI 功能
- [x] MiMo API 集成的 AI 智能问答
- [x] Supabase pgvector 语义搜索
- [x] 上下文感知（携带当前课题内容）
- [x] 流式响应

### 用户系统
- [x] 邮箱注册/登录
- [x] Magic Link 一键登录
- [x] 忘记密码 + 邮箱重置
- [x] 密码格式校验（英文字母 + 数字 + 符号）

### 学习功能
- [x] 学习进度追踪（完成标记 + 进度条）
- [x] 学习计时（静默记录在每个课题停留的时间）
- [x] 练习系统（选择/填空/简答 + 自动评分 + 解析）
- [x] 错题本（自动记录错题 + 按课题分组）
- [x] 笔记系统（每课题独立笔记）
- [x] 数据导入/导出（JSON 格式）

## 规划中

### Phase 1：体验优化

- [ ] **暗色模式** — CSS 变量 + 系统偏好检测
- [ ] **响应式优化** — 移动端练习体验改进
- [ ] **搜索增强** — 按学科筛选、结果标注所属学科
- [ ] **进度页增强** — 学习日历（哪天学了什么）、学习时长统计图表

### Phase 2：内容扩展

- [ ] **软件设计师（中级）** — 新增数据结构、算法、操作系统等模块
- [ ] **系统架构设计师（高级）** — 软件架构、系统设计
- [ ] **更多图表组件** — TCP 拥塞控制、ARP 过程、DNS 解析流程
- [ ] **课题内容完善** — 部分课题的练习题补充到 5 道

### Phase 3：社交与激励

- [ ] **学习排行榜** — 基于学习时长/完成课题数
- [ ] **成就系统** — 徽章、连续学习天数
- [ ] **分享功能** — 分享学习进度到社交媒体
- [ ] **社区问答** — 用户间互相提问

### Phase 4：商业化

- [ ] **付费课程** — 部分高级内容需要付费解锁
- [ ] **模拟考试** — 按真实考试时间和题型组卷
- [ ] **AI 知识图谱** — 可视化知识点之间的依赖关系
- [ ] **学习报告** — 每周/月学习报告（邮件推送）

### Phase 5：平台化

- [ ] **用户生成内容（UGC）** — 用户可创建和分享自己的课题
- [ ] **教师后台** — 班级管理、作业布置、成绩查看
- [ ] **API 开放** — 允许第三方接入课程数据
- [ ] **多语言支持** — 英文界面

## 技术债

| 优先级 | 问题 | 计划 |
|--------|------|------|
| P0 | localStorage 数据换设备丢失 | 迁移到 Supabase 用户表 |
| P1 | AI 推荐问题硬编码 3 个 | 基于进度动态生成 |
| P1 | 密码重置流程需要 Supabase 邮件模板配置 | 确认 Supabase Dashboard 设置 |
| P2 | 课题文件越来越多（63 个），index.ts import 繁重 | 考虑动态导入或文件系统扫描 |
| P2 | 图表组件缺少移动端适配 | 响应式改造 |
| P3 | 部分课程内容的练习题不足 3 道 | 补充题目 |

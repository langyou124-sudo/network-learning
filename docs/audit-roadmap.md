**内容侧（值得肯定）**

- 乔姆斯基型别自相矛盾

## Phase 1 立即修（正确性收敛）

**目标**：消除用户可见的判错、渲染静默丢失与知识硬伤，恢复"练习→反馈"闭环的可信度。
**原则**：一次修好判分内核，不要各科各修一套。

### 1.1 统一判分内核
以 `src/app/learn/network/[moduleId]/[topicId]/page.tsx` 为基准改造全部 5 个练习页：

- **choice 一律比对字母** —— 303 与 802 页面现存 `value={opt}` 存选项原文、与数据侧 answer 字母永不相等导致 46 道+全部判错，照抄 network 的 `String.fromCharCode(65+i)` 实现
- **fill 废除 `answer.join(',')` 与裸 `===`**：
  - 多空题（题干 ≥2 个 `______`）拆多输入框逐空比对
  - 区分两种数组语义：「逐空答案」（如 `['MAC','IP']`）与「任一可接受变体」（如 `['SLAAC','Stateless Address Autoconfiguration']`、`['结构','结构层']`）
  - 统一 `trim` / 忽略大小写 / 全半角 / Unicode 减号（U+2212）归一化
  - 覆盖网络约 66 题、马克思主义 11 道多空、软考 SD 4 数组 + 7 单串、303 与 802 含符号填空

### 1.2 short-answer 改自评模式
- 展示参考答案 + 评分要点，用户勾选「已掌握/需复习」
- 不计入自动判分、不写入错题本
- 覆盖网络 40、马克思 54、303 44、802 各科简答、SD 11 道
- 现有 `saveMistake` 逻辑同步改为仅记录客观题错题

### 1.3 修 3 处答案结构缺陷

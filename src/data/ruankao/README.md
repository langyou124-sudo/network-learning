# 软考内容编写指南

## 文件结构
每个科目一个目录，每个目录下有 `index.ts` 导出模块数据。
课题内容写在对应的 `.ts` 文件中，格式与网络工程课程一致（Markdown + Quiz）。

## 内容编写格式

每个课题的 `content` 字段使用 Markdown 格式，支持：
- 标题：`#` `##` `###`
- 列表：`-` 或 `1.`
- 代码块：` ``` `
- 表格：标准 Markdown 表格
- 引用：`>`
- 嵌入图表：`<Diagram type="组件名" />`
- 嵌入术语卡：`<Glossary terms="编码后的JSON" />`

每个课题的 `quizzes` 字段支持：
- 选择题：`type: 'choice'`，需提供 `options` 数组
- 填空题：`type: 'fill'`
- 简答题：`type: 'short-answer'`
